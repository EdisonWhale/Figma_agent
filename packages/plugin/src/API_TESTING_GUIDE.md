# Figma API 综合测试工具使用指南

## 概览

本文档介绍新增的**综合 Figma API 测试工具**，这是一个完整的手动测试界面，涵盖了插件中所有 22 个 Figma API 操作。

## 功能特性

### 🎯 全面覆盖
- **22 个不同的 API 操作**，分为 6 个功能类别
- **参数化测试**：每个操作都有相应的参数输入界面
- **实时结果**：所有测试结果实时显示，包括成功、错误和信息状态
- **状态跟踪**：显示当前页面状态、选中元素等信息

### 🛠 功能分类

#### 1. 📄 页面信息
- `get_current_page_info` - 获取当前页面信息和所有元素
- `get_selected_elements` - 获取当前选中的元素 
- `get_page_statistics` - 获取页面统计信息（元素数量、类型分布等）
- `query_elements` - 根据类型或名称模式查询元素
- `get_element_details` - 获取特定元素的详细信息

#### 2. ➕ 基础创建
- `create_sticky_note` - 在 FigJam 中创建便签
- `create_rectangle` - 创建矩形
- `create_ellipse` - 创建椭圆
- `create_text` - 创建文本元素
- `create_connector` - 创建元素间的连接器

#### 3. 🔧 元素管理
- `update_element` - 更新元素属性（位置、大小、透明度等）
- `duplicate_element` - 复制元素
- `delete_elements` - 删除单个或多个元素
- `select_elements` - 选择元素

#### 4. 📐 布局排列
- `arrange_elements` - 水平、垂直或网格排列元素
- `align_elements` - 对齐元素（左对齐、居中等）

#### 5. 🚀 高级创建
- `create_sticky_batch` - 批量创建便签（行、列、网格布局）
- `create_flowchart` - 创建流程图（自动布局和连接）
- `create_mindmap` - 创建思维导图（放射状布局）
- `create_polygon` - 创建多边形
- `create_star` - 创建星形
- `create_shape_with_text` - 创建带文字的形状
- `create_frame` - 创建框架容器
- `create_section` - 创建区域

#### 6. 📦 分组操作
- `group_elements` - 将多个元素分组
- `ungroup_elements` - 解散分组

## 使用方式

### 启动测试工具
1. 打开 Figma/FigJam 插件
2. 点击右上角 **"API 测试"** 按钮
3. 选择 **"综合模式"**（默认）或切换到简单模式

### 测试流程
1. **选择功能标签**：点击顶部的功能分类标签
2. **配置参数**：根据需要调整测试参数
3. **执行测试**：点击相应的测试按钮
4. **查看结果**：在底部结果区域查看执行状态和返回数据

### 测试最佳实践

#### 页面信息测试
- 首先运行 **"获取页面信息"** 来了解当前页面状态
- 使用 **"获取选中元素"** 来测试依赖选中元素的操作

#### 创建元素测试
- 测试不同的参数组合（颜色、大小、位置等）
- 在 FigJam 中测试便签和连接器
- 在 Figma 中测试形状和文本

#### 元素管理测试
- 先选择一些元素，然后测试更新、复制、删除操作
- 注意观察元素状态的变化

#### 高级功能测试
- **批量操作**：测试不同数量和布局的批量创建
- **流程图**：测试不同节点数量的流程图生成
- **思维导图**：测试不同分支数量的思维导图

## 参数说明

### 通用参数
- **位置** (x, y)：元素在画布上的坐标
- **尺寸** (width, height)：元素的宽度和高度
- **颜色** (r, g, b)：RGB 颜色值（0-1 范围）
- **名称**：元素的显示名称

### 特殊参数
- **便签颜色**：yellow, green, blue, pink, orange
- **文本对齐**：LEFT, CENTER, RIGHT
- **排列方向**：horizontal, vertical, grid
- **布局模式**：ROW, COLUMN, GRID（批量操作）

## 结果解读

### 状态类型
- 🔵 **Info**：信息性消息（操作开始、元素创建等）
- ✅ **Success**：操作成功完成
- ❌ **Error**：操作失败或出现错误

### 结果数据
每个操作都会返回相关数据：
- **元素ID**：新创建元素的唯一标识符
- **统计信息**：页面元素数量、类型分布等
- **批量结果**：成功和失败的元素数量
- **位置信息**：元素的坐标和尺寸

## 技术细节

### 支持的编辑器
- **Figma**：支持所有形状、文本、框架等操作
- **FigJam**：支持便签、连接器、分组等操作

### API 客户端功能
- **缓存机制**：自动缓存页面信息和元素详情
- **错误处理**：完善的错误处理和重试机制
- **事件监听**：监听元素创建、更新、删除事件
- **验证系统**：输入参数验证和类型检查

### 调试信息
- 所有操作都会记录详细的调试信息
- 错误消息包含具体的失败原因
- 操作数据以 JSON 格式显示，方便开发调试

## 扩展性

该测试工具的设计具有良好的扩展性：
- 新增 API 操作时，只需在对应类别中添加测试函数
- 参数输入界面支持文本、数字、下拉选择等多种类型
- 结果显示系统支持复杂的数据结构展示

## 总结

综合 Figma API 测试工具为开发者提供了一个完整的手动测试环境，可以：
- 验证所有 API 操作的功能正确性
- 测试不同参数组合的效果
- 调试复杂的批量操作和高级功能
- 了解 API 的返回数据结构和错误处理机制

通过这个工具，开发者可以更加高效地测试和验证 Figma 插件的 API 集成。
